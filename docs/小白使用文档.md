# demo-page-builder 小白使用文档

> 本教程写给**第一次用**的人：不需要会写代码，跟着步骤做，就能让 AI 帮你做出网页 demo。

## 1. 这是什么？能帮我做什么？

demo-page-builder 是一个"网页 demo 生成技能"。把它装到 AI 编程助手（如 Kimi Code、Claude Code、Codex、Gemini CLI、Cursor、opencode 等）里以后，你只要**用大白话说需求**，AI 就会自动完成：搭工程 → 写页面 → 启动服务 → 把网页地址发给你。

适合做的事情：

| 你想做什么 | 可以这样跟 AI 说 |
|---|---|
| 产品宣传页 / 落地页 | "帮我做一个产品介绍的落地页" |
| 登录 / 注册页面 | "生成一个登录页 demo" |
| 数据看板 / 仪表盘 | "做一个数据看板 demo，左边是菜单，右边是图表" |
| 照着设计图做 | "照这张截图做一个一样的页面"（把图发给 AI） |
| 原型 / 效果演示 | "写个页面原型：三个 tab，每个 tab 一个表单" |

生成的是**浏览器里能打开的网页**，用来快速看效果、对需求，非常适合给客户或产品经理演示。

## 2. 开始前需要准备什么？

只需要三样东西，**不需要**会写代码、不需要懂前端：

1. 一台电脑（Windows / macOS / Linux 都可以）
2. 一个支持"技能（skills）"的 AI 编程助手，例如：Kimi Code CLI、Claude Code、Codex、Gemini CLI、opencode、Cursor 等
3. 电脑能联网（第一次使用需要下载一些工具和依赖，通常几分钟）

建议再准备一个**专门放这个项目的文件夹**（空文件夹就行），让 AI 只在这个文件夹里干活，不乱动其他地方。

## 3. 安装技能（推荐让 AI 自己装）

### 方式一：一句话自动安装（推荐）

1. 打开 AI 助手，把这句话发给它：

```
把 https://github.com/zhiquanchi/prd-demo-skills 仓库里的 skills 安装好
```

2. 等它装完，**关掉当前会话，新开一个会话**。
3. 让 AI 列出可用技能（不同助手命令不一样，常见的是 `/skills` 或直接问"你现在有哪些技能"），确认列表里有 **demo-page-builder** 就说明装好了。

> 小提示：如果 AI 说"项目不是 git 仓库"，它会自动改装到"用户级"目录，照它说的做即可；装完同样要重开会话确认一次。

### 方式二：手动复制（备用）

从仓库里拿到 `demo-page-builder` 这个文件夹，按你的 AI 助手要求放到指定位置（项目级或用户级的 skills 目录），具体位置对照表见仓库 README 的"安装方式二"。复制完同样**重开会话**，并确认技能列表里有它。

## 4. 开始做第一个页面

1. 打开 AI 助手，把工作目录切到你想放页面的文件夹（比如 `D:\我的demo` 或 `~/demo`）。空文件夹也没关系。
2. 直接用大白话提需求，比如：
   - "帮我做一个产品介绍落地页，包含导航、产品亮点、价格表、底部联系信息"
   - "生成一个登录页 demo，左边品牌图，右边表单"
   - "照这张截图做一个一样的页面"（把截图拖给 AI）
3. 然后**耐心等它干活**。第一次使用它会自动：
   - 检查电脑环境（没装 Node.js 会先装，或提示你装）
   - 在当前文件夹里搭好工程、下载依赖（这一步最久，可能 1-5 分钟）
   - 写页面代码、启动服务
4. 它会把访问地址发给你，通常是：

```
http://localhost:8000/
```

也可能是带具体页面的地址，比如 `http://localhost:8000/login`。**把这个地址在浏览器里打开**，就能看到页面了。

## 5. 看效果、提修改、确认交付

1. **看效果**：在浏览器里打开 AI 发的地址。
2. **提意见**：不满意直接说人话，比如"按钮改成蓝色""卡片要能点击""加一个搜索框"。AI 改完会**重新给你地址**；如果页面没变化，先强制刷新一下：`Ctrl + Shift + R`（Windows）或 `Cmd + Shift + R`（Mac）。
3. **确认满意**：觉得可以了，说"可以了 / 满意 / 就这样"。AI 会做两件收尾的事：
   - 打一个交付标签，例如 `deliver-登录页-20260821-01`（相当于给这次交付存一个版本号）
   - 生成一份**交接文档**（放在 `docs/handover/` 目录），里面写清楚页面怎么用、怎么交接，方便以后别人接手。

## 6. 常见问题（FAQ）

| 问题 | 怎么办 |
|---|---|
| 装完技能，AI 不认 demo-page-builder | 重开一个新会话，用 `/skills` 或直接问"你现在有哪些技能"确认；还不行就换成用户级目录重装一次 |
| 提示"没有 Node.js" | 个人电脑：去 Node.js 官网下载 LTS 版装上；公司电脑：可能是网络或权限限制，需要找 IT 开通，或让 AI 用公司内网镜像 |
| 第一次下载依赖特别慢 / 像卡住了 | 正常，首次要下载很多文件，耐心等 1-5 分钟；期间可以看 AI 的进度播报 |
| 浏览器打不开 AI 给的地址 | 先确认服务是否还在运行；如果端口被占用，AI 会换一个端口并给你新地址，用新地址打开 |
| 页面改了但没变化 | 强制刷新：`Ctrl + Shift + R`（Windows）/ `Cmd + Shift + R`（Mac）。Windows 里用 WSL 时，AI 需要重新构建，属于正常流程 |
| 页面里的数据是真的吗？ | demo 页面用的是**假数据**（示例数据），只是为了看效果；要接真实数据需要后续正式开发 |
| 会不会弄坏我的电脑或其他项目？ | 不会。AI 只在当前文件夹里干活，不写其他目录；动文件前会先报告 |

## 7. 三个小提醒

1. **每次拿到新地址先打开看**，有问题立刻反馈，改起来最快。
2. **一次说清楚要改哪些**（比如"这 8 张卡片都要能点击"），AI 会逐项核对，避免只改了一部分。
3. **页面确认满意后再交付**，AI 会打版本标签并生成交接文档，之后随便改，版本都有记录。

更详细的技术说明、安装对照表、环境要求，见仓库根目录的 `README.md`。
